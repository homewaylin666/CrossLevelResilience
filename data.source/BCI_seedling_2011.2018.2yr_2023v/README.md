# Title of Dataset: Long-term seedling and small sapling census data from the Barro Colorado Island 50 ha Forest Dynamics Plot, Panama
---

This compressed directory contains the main data and associated information from 14 censuses of seedlings and small saplings in the Barro Colorado Island 50 ha Forest Dynamics Plot (Panama) conducted bewteen 2001 and 2018. In each census, all freestanding woody individuals ≥20 cm tall and <1 cm dbh (hereafter simply referred to as seedlings) were tagged, mapped, measured, and identified to species in 19,313 1-m2 seedling plots. 

## Description of the data and file structure

The file "MetadataS1" contains a complete description of the methods and background information. Please read this carefully before using the data.
The compressed folder "DataS1" contains the following files:
-"BCI.seedling.census.data.2001.to.2018.csv" - main data file containing one row per observation (an individual in a census)
-"BCI.seedling.census.species.list.csv" - file containing the species 6-letter code (used in the main data file), genus, species, family, and growth form for each species encountered in the census
-"BCI.seedling.plot.info.csv" - file containing the coordinates of each 1-m2 seedling plot and an indication of whether the plot was censuses or skipped (see Metadata for details)
