How the layers join — three independent linking dimensions

① Space

All BCI layers share the 50-ha coordinate system. Seedling plots sit at the centre of every 5×5 m quadrat; the 200 SWP sites and every tagged tree carry x/y → exact nesting individual↔population↔community.

② Taxonomy

The 2019 taxonomy table reconciles 6-letter (tree/seedling) and 4-letter (Kupers) codes to 328 accepted species. Join by Latin name, not by code.

③ Disturbance

A shared ENSO history (1982–83, 1997–98, 2015–16) is the common press. The 2015–16 event is the one covered simultaneously by seedlings, trees and the SWP map; individual-level data start in 2001, so low-level multi-event replication is limited to 2015–16.

★ A useful find inside the abiotic folder

Kupers62species.list.xlsx is not a plain list — it contains the published supplementary Tables S4–S7: per-species growth and mortality response parameters to soil water potential for all 62 species. That is a ready-made individual-level drought-response layer you can use or validate against.

Resistance vs. recovery — a coverage asymmetry to design around

The full tree census ends in 2015, so for the 2015–16 ENSO the community-level full-census signal is essentially drought onset / resistance, not recovery. Recovery at the adult level for that event must come from the annual dendrometer 2015–2020 (growth recovery, subset of trees) and/or from the earlier droughts (1982–83, 1997–98) where post-drought full censuses exist. Seedlings (to 2018) give individual/population recovery. Plan the analysis so each level is asked for the resilience component it can actually support.

⚠ The one open data decision: do we need the physiology layer at all?

Because the base unit is the individual demographic level, physiology is optional. SAPFLUXNET has no BCI site (breaks "same site"); the only BCI sap flow that exists (NGEE-Tropics) is 2022, not 2015–16 (breaks "same disturbance"). Recommendation: do not download the >3 GB SAPFLUXNET set unless the chapter explicitly needs a sub-daily physiological rate — and then only as a trait-space donor. The core hypothesis is fully testable with the four open BCI datasets.

Housekeeping: seedling folder is labelled 2011.2018 but data span 2001–2018 (14 censuses); 2015 itself is not a census year — the 2015–16 signal is the 2014→2016 interval.
